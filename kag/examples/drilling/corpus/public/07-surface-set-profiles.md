# Epiroc表镶取心钻头的冠部形状

Epiroc表镶取心钻头产品页说明，SPC是每克拉的金刚石颗粒数，不是金刚石质量等级。

STEP阶梯式冠部有利于较快进尺，常配绳索取心钻具，但在破碎岩层中相对脆弱，不能据此推荐它处理所有破碎地层。PILOT导向式适合软至中等硬度岩层；ANGLED PILOT斜导向式用于非常破碎的地层。FACE DISCHARGE面排水形式有助于取得十分易碎地层的岩心。

性质：厂家产品说明的中文摘要，名称对应本页产品结构；不是通用施工规程。
